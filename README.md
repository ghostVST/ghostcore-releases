# ghostVST product releases

Official binary releases for individual ghostVST products, including Ghost Rack.

Choose the release for your product. Each release provides a macOS Universal ZIP, its product manifest, and SHA-256 checksums. The ZIP includes AU/VST3 bundles, documentation, the product EULA, and third-party notices. Refer to the release notes for system requirements and to the included legal materials for licensing terms.
